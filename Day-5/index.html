Real Life থেকে শুরু করি

তুমি তোমার বন্ধুকে বললে —

"ভাই, ৫০০ টাকা দরকার।"

বন্ধু বললো —

"এখন নেই, কাল দেব।"

এটাই Promise।
বন্ধু এখনই টাকা দিতে পারেনি,
কিন্তু একটা প্রতিশ্রুতি দিয়েছে।
কাল হয় টাকা দেবে — অথবা বলবে "দিতে পারব না"।

JavaScript এ একই ঘটনা

তুমি server কে বললে — "user এর data দাও"
Server বললো — "এখন দিতে পারব না, একটু সময় লাগবে"
Server একটা Promise দিলো।

কিছুক্ষণ পরে হয় data আসবে — অথবা error আসবে।

Promise এর ভেতরে কী আছে

const promise = new Promise((resolve, reject) => {
    // এখানে async কাজ হয়

    // কাজ সফল হলে
    resolve("সফল!");

    // কাজ ব্যর্থ হলে
    reject("ব্যর্থ!");
});
  • resolve → বন্ধু টাকা দিলো ✅
  • reject → বন্ধু বললো "দিতে পারব না" ❌

তিনটা অবস্থা

  • Pending → বন্ধু এখনো সিদ্ধান্ত নেয়নি ⏳
  • Resolved → বন্ধু টাকা দিলো ✅
  • Rejected → বন্ধু দিতে পারলো না ❌

এখন সবচেয়ে Simple Example

// একটা Promise বানালাম
const myPromise = new Promise((resolve, reject) => {
    setTimeout(() => {
        resolve("টাকা পেয়েছি!"); // ২ সেকেন্ড পরে সফল
    }, 2000);
});

// Promise এর result নিচ্ছি
myPromise.then((result) => {
    console.log(result); // "টাকা পেয়েছি!"
});

console.log("Promise এর জন্য অপেক্ষা না করে কাজ চলছে...");

Output —

Promise এর জন্য অপেক্ষা না করে কাজ চলছে...

(২ সেকেন্ড পরে...)

টাকা পেয়েছি!

JS থেমে থাকেনি — অন্য কাজ করেছে।

.then() আর .catch() কী

myPromise
    .then((result) => {
        // resolve হলে এখানে আসবে
        console.log("সফল:", result);
    })
    .catch((error) => {
        // reject হলে এখানে আসবে
        console.log("ব্যর্থ:", error);
    });
  • .then() → বন্ধু টাকা দিলে কী করব
  • .catch() → বন্ধু না দিলে কী করব
