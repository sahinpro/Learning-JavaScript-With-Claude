চিন্তা করো তুমি একটা Factory বানাচ্ছ

তুমি ফোন বানানোর factory দিলে।

Factory তে একটা ছাঁচ আছে —

প্রতিটা ফোনে থাকবে:
- brand name
- color
- battery
- call() করার ক্ষমতা
- charge() করার ক্ষমতা

এই ছাঁচটাই হলো Class।

ছাঁচ থেকে যতগুলো ফোন বানাও — প্রতিটাই Object। 

ছাঁচ (Class)     → Phone
বানানো ফোন ১     → nokia  = new Phone("Nokia", "black")
বানানো ফোন ২     → samsung = new Phone("Samsung", "white")

এখন Code এ দেখো

// এটা ছাঁচ — কোনো real ফোন না
class Phone {

    // factory তে ফোন বানানোর মুহূর্ত
    constructor(brand, color) {
        this.brand = brand;   // এই ফোনের brand
        this.color = color;   // এই ফোনের color
        this.battery = 100;   // সব ফোন শুরুতে 100%
    }

    // ফোনের ক্ষমতা
    call(number) {
        console.log(`${this.brand} is calling ${number}`);
    }

    charge() {
        this.battery = 100;
        console.log(`${this.brand} is fully charged!`);
    }
}

this কী?

এটাই সবচেয়ে confusing জিনিস।

const nokia = new Phone("Nokia", "black");
const samsung = new Phone("Samsung", "white");

nokia.call("01700000000");
// Nokia is calling 01700000000

samsung.call("01800000000");
// Samsung is calling 01800000000

this মানে — "যে object এই moment এ কাজ করছে সে নিজে।" 

nokia.call()   → this = nokia
samsung.call() → this = samsung

একই method — কিন্তু this আলাদা। 🎯

constructor কী?

const nokia = new Phone("Nokia", "black");
//                       ↑        ↑
//                    brand     color

new Phone(...) লিখলে constructor automatically চলে। 

constructor(brand, color) {
    this.brand = brand; // nokia.brand = "Nokia"
    this.color = color; // nokia.color = "black"
    this.battery = 100; // nokia.battery = 100
}

Constructor মানে — "ফোন বানানোর মুহূর্তে কী কী set করতে হবে।"

new কী করে?

const nokia = new Phone("Nokia", "black");

new লিখলে JS তিনটা কাজ করে —

1. একটা নতুন খালি object তৈরি করে {}
2. constructor চালায় — property set করে
3. সেই object return করে

পুরো ছবিটা একসাথে

class Phone {                          // ছাঁচ
    constructor(brand, color) {        // বানানোর নিয়ম
        this.brand = brand;            // এই ফোনের brand
        this.color = color;            // এই ফোনের color
        this.battery = 100;
    }

    call(number) {                     // ফোনের ক্ষমতা
        console.log(`${this.brand} calling ${number}`);
    }
}

// ছাঁচ থেকে দুটো আলাদা ফোন বানালাম
const nokia   = new Phone("Nokia", "black");
const samsung = new Phone("Samsung", "white");

// দুটো আলাদা — কিন্তু একই ছাঁচ থেকে
nokia.call("017...");    // Nokia calling 017...
samsung.call("018...");  // Samsung calling 018...

এখন তোমার মাথায় যা থাকবে

Class       → ছাঁচ / blueprint
constructor → বানানোর মুহূর্তে চলে
this        → এই specific object নিজে
new         → ছাঁচ থেকে object বানায়
method      → object এর ক্ষমতা
property    → object এর তথ্য
